# DS_ML_Lab

A growing collection of hands-on code practices from my journey into Data Science and Machine Learning.

## Overview

This repository is my personal laboratory: a living archive of the code exercises, experiments, and practices I have found interesting and valuable while studying Data Science and Machine Learning.

It is organized by library. Each folder corresponds to a Python library or topic I am learning, and holds the practices worth keeping and revisiting. As my path toward becoming a Data Scientist and Machine Learning Engineer progresses, new folders and practices are added over time.

This is not a showcase of finished projects. It is a workbench: a place to try things out, break them, understand them, and keep the experiments that taught me something worth remembering.

## Repository structure

```
DS_ML_Laboratory/
├── numpy/          # Vectorized operations, broadcasting, indexing
├── pandas/         # Series, DataFrame, groupby, merging, reshaping
├── matplotlib/     # Object-oriented API, subplots, customization
├── seaborn/        # Statistical visualizations
├── scikit-learn/   # Pipelines, modeling, evaluation
├── pytorch/        # Tensors, autograd, neural networks
└── ...             # More libraries and topics added as I learn them
```

Each folder contains standalone practices (Python scripts and/or Jupyter notebooks), each focused on a specific concept within that library.

## Purpose

- Keep a curated record of the code practices worth revisiting.
- Reinforce learning through deliberate, hands-on repetition.
- Track progress across tools and topics over time.

## Environment

- Python 3
- Conda environments
- Jupyter Notebooks

## Status

Actively maintained. This repository grows continuously as my learning advances.
